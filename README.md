# NeetCode 150

Java solutions and tests for the [NeetCode 150](https://neetcode.io/roadmap) problem set — a curated list of 150 LeetCode problems covering common interview patterns.

## Setup

Requires Java 25 and Maven.

```sh
mvn test
```

Run a single test class:

```sh
mvn -Dtest=ProblemNameTest test
```

## Project layout

```
src/
├── main/java/com/albin/neetcode/   # solution implementations
└── test/java/com/albin/neetcode/   # JUnit tests
```
